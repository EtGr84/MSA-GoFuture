# Task3. Обеспечиваем высокую нагрузку

## Контекст

GoFuture должна обеспечить 99,99% доступности и низкую задержку для пользователей в Юго-Восточной Азии и Южной Америке. Для этого платформа разворачивается в четырёх пользовательских runtime-регионах: Singapore, Jakarta, Sao Paulo и Santiago. Control/partner region остаётся отдельным управляющим контуром и не засчитывается как пользовательский регион высокой доступности.
