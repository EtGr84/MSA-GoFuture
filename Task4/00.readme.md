# Task4 / Проектируем платформу данных

---
---
--

## Контекст
GoFuture нужна единая платформа данных для динамического ценообразования, прогнозирования спроса, fraud detection, операционной аналитики и BI. Источники данных — доменные микросервисы, Kafka-события, CDC из сервисных БД и внешние справочники.

---

## Принятые решения

- Batch processing: Spark для backfill, обучения моделей и тяжёлых агрегаций.
- Хранилища: object storage/data lake для bronze/silver/gold, ClickHouse для BI, Feature Store для online/offline признаков.
- ML: training pipelines, model registry, model serving для Pricing и Fraud.
- Основной поток событий: Kafka topics из Task2.
- Stream processing: Flink для realtime-признаков, спроса/предложения и fraud features.
- Data quality: schema contracts, validation gates, freshness/completeness checks, lineage, data catalog, мониторинг качества.
