# Task5 / Мультитенантная платформа

## Контекст

GoFuture хочет быстро подключать партнёров в новых регионах с изоляцией данных, SSO, ролевым доступом, кастомизацией функциональности и наблюдаемостью по каждому tenant.

## Предлагаемые решения

- RBAC + ABAC: роль задаёт тип действий, атрибуты `tenant_id`, `region_id`, `partner_id`, `data_class` ограничивают область данных.
- Изоляция данных: tenant-scoped schemas/DBs, tenant keys в KMS, RLS для shared tables, dedicated data plane для крупных или регулируемых партнёров.
- Onboarding автоматизирован через Partner Portal, workflow engine, IAM provisioning, IaC/GitOps и проверку readiness.
- Единый IAM/IdP с OIDC/SAML SSO, MFA, service accounts и short-lived tokens.
- Tenant Registry как источник правды о партнёре, регионе, тарифах, feature flags, compliance-профиле и изоляции данных.
- Мониторинг по tenant labels: SLO, usage, cost, security events, API quotas, data isolation alerts.
